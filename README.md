# ValveWise

A graph-based water distribution network failure and resilience optimizer.

## Technology
- C for graph algorithms and simulation
- HTML, CSS and JavaScript for visualization
- EPANET-compatible network datasets

## Team responsibilities
- Person 1: Graph engine, data parsing, BFS/DFS, failure simulation, connectivity analysis and network visualization
- Person 2: Valve isolation, stuck-valve analysis, criticality ranking and valve-placement optimization

Project initialization.
